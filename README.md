# ドット絵エディタ

Claude Code が生成したドット絵を、ブラウザで手直しするための道具です。
手直しの傾向を Claude Code が読み取って、次に描くドット絵に反映します。

## 使い方

1. `pixel/editor.html` を **デスクトップ版の Google Chrome** で開きます（ファイルを Chrome のウィンドウにドラッグしても開けます）
2. 「pixel フォルダを開く」を押し、`pixel` フォルダを選びます。読み書きの許可を聞かれたら「許可」を選びます
   - 2回目からは「前回のフォルダを開く」で開けます
3. 一覧でドット絵をクリックすると、編集画面が開きます
4. 手直ししたら「上書き保存」（Ctrl+S）を押します。一覧に「手直し済み」と表示されます
5. Claude Code に伝えたいことがあれば、右側の「メモ」に書いてから保存します（例：顔をもっと幼く）
6. 手直しが終わったら、Claude Code に **「手直しを反映して」** と頼みます

## 編集画面でできること

| やりたいこと | 操作 |
|---|---|
| 描く | ペン（B）で左クリック。右クリックで消す |
| 消す | 消しゴム（E） |
| まとめて塗る | 塗りつぶし（F） |
| 色を拾う | スポイト（I）、または Alt＋クリック |
| 左右対称に描く | 「左右対称」（M） |
| 拡大・縮小 | ＋ − ボタン、Ctrl＋マウスホイール、「全体」（0） |
| グリッド | 「グリッド」（G） |
| 前後のフレームを薄く重ねる | 「前後のフレームを透かす」（T） |
| フレームを増やす・減らす | 下の「追加」「複製」「削除」「前へ移動」「後ろへ移動」 |
| フレームを切り替える | 下のフレームをクリック、または ← → |
| 動きを見る | 右上のプレビュー（実寸・2倍・4倍）。fps で速さを変えられます |
| 最初に生成された版と比べる | 「比較を表示する」、または O キーを押している間 |
| 元に戻す・やり直す | Ctrl+Z ／ Ctrl+Y |

色はパレット（`palette.json`）の色だけ使えます。

## PNG の書き出し

- 編集画面の「このフレームをPNG」「スプライトシートPNG」（全フレームを横に並べた1枚）
- 一覧画面の「全スプライトをPNG書き出し」
- 書き出し先は `pixel/export` フォルダです。倍率は一覧画面の「書き出し倍率」で選べます

## パレット

一覧画面の「パレット」で全色を確認できます。
確定するまでは色をクリックして変えられます（その色を使っている全部のドット絵の色が変わります）。
良ければ「このパレットで確定」を押します。確定後に変えたいときは Claude Code に頼みます。

## フォルダの中身

```
pixel/
  editor.html        … エディタ
  palette.json       … 共通パレット
  style-guide.md     … 描き方の規則（Claude Code が読み書きします）
  sprites/           … ドット絵のデータ（エディタで保存するとここが書き換わります）
  sprites/_original/ … 最初に生成された版の控え（比較用。触らないでください）
  export/            … 書き出した PNG
```
