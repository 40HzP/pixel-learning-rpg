# ドット絵生成＋編集ツール 仕様書（Claude Code向け）

対象：アプリ案「起動中だけ主人公が強くなっていく暇つぶし系ローグライクドット絵ゲーム（勉強機能付き）」
設計ページ：https://app.notion.com/p/3e9bafd061fe8020af5cd7e51d08c4ab

---

## 1. 目的

- Claude Code がドット絵をテキストデータとして生成する
- 40HzP がブラウザ上のエディタで手直しする
- 手直しの傾向を Claude Code が読み取り、次の生成に反映する

## 2. 前提・制約（必ず守る）

- 40HzP はプログラミングをしない。**継続的な保守やデバッグが要る構成にしない**
- エディタは **単一のHTMLファイル**。サーバー、ビルド工程、アカウントは使わない
- 外部ライブラリは原則使わない。使う場合はCDNから読み込む1つまで
- 画像生成AIのAPIは使わない。ドット絵は Claude Code がデータとして直接書く
- 対象ブラウザ：デスクトップ版 Chrome（フォルダの読み書きに File System Access API を使う）

## 3. フォルダ構成

```
pixel/
  editor.html            … エディタ本体（単一ファイル）
  palette.json           … ゲーム共通の固定パレット
  style-guide.md         … 描き方の規則。生成のたびに参照し、手直しの傾向を追記する
  sprites/               … 正本（スプライトJSON）
  sprites/_original/     … Claude Code が最初に生成した版の控え（差分確認用）
  export/                … 書き出したPNGとスプライトシート
```

## 4. データ形式

### palette.json
- 32色以内の固定パレット。各色に1文字のキーを割り当てる（`0`〜`9`、`a`〜`v`）
- `.` は透明
- パレットは最初に Claude Code が案を作り、40HzP が確定させる

### スプライトJSON（`sprites/<name>.json`）

```json
{
  "name": "hero_idle",
  "category": "character",
  "w": 16,
  "h": 16,
  "fps": 4,
  "frames": [
    [
      "......0000......",
      ".....011110.....",
      "..."
    ]
  ],
  "edited": false,
  "note": ""
}
```

- 1行＝1ピクセル行、1文字＝1ピクセル。テキストなので差分がそのまま読める
- `edited` はエディタで保存すると `true` になる
- `note` は40HzPがエディタから残すメモ欄（「顔をもっと幼く」など）

## 5. サイズの基準（仮。試作で調整）

| 種類 | サイズ | フレーム |
|---|---|---|
| 主人公・仲間・中ボス（人間） | 16×16 | 待機2枚、攻撃2枚 |
| ザコ魔物 | 16×16 | 待機2枚 |
| 小ボス | 32×32 | 待機2枚 |
| 階層の背景 | 90×160（縦長） | 1枚 |
| アイコン | 8×8 | 1枚 |

## 6. エディタの機能（最初の版）

**一覧画面**
- フォルダを開くと、全スプライトをサムネイルで並べる
- カテゴリと `edited` で絞り込む

**編集画面**
- 道具：ペン、消しゴム、塗りつぶし、スポイト、左右対称モード
- パレットは `palette.json` に固定。パレット外の色は使えない
- 拡大表示とグリッド表示の切り替え
- フレームの追加・複製・削除、前後フレームの透かし表示
- アニメーションのプレビュー（`fps` に従う）
- 実寸・2倍・4倍のプレビュー（スマホでの見え方の確認用）
- 元に戻す・やり直す
- **生成時の版（`_original`）との比較表示**
- メモ欄（`note`）

**保存と書き出し**
- 上書き保存で `sprites/<name>.json` に書き戻す
- PNG書き出し：1フレーム単位と、横並びのスプライトシート
- 全スプライトの一括書き出し

## 7. 生成と手直しの流れ

1. Claude Code が `style-guide.md` を読んでスプライトJSONを生成し、同じものを `_original/` にも置く
2. 40HzP がエディタで手直しし、必要なら `note` に指示を書く
3. 40HzP が Claude Code に「手直しを反映して」と頼む
4. Claude Code は `edited: true` のファイルを `_original/` と比較し、**手直しの傾向**（輪郭の太さ、目の位置、影の付け方など）を `style-guide.md` に追記する
5. 次の生成から、更新された `style-guide.md` に従う

## 8. style-guide.md の初期内容（Claude Code が作る）

- 輪郭：1pxの暗色
- 光源：左上
- 人間キャラの頭身と、頭部のピクセル数
- 魔物の方針：ザコは「俗説」、小ボスは「かつての誤った学説」を擬人化・擬物化したもの。モチーフは設計ページの魔物系の節を参照
- 既存の作品のキャラクターやデザインに似せない

## 9. 最初に作る分（試作用）

- 主人公（待機・攻撃）
- ザコ3体：サンビョウキンギョ、ジュッパーノウ、ミエナイコウモリ
- 中ボス1体：小学校教師
- 背景1枚：最初の階層
- 共通パレット案

## 10. 完了条件

- `editor.html` をChromeで開き、`pixel/` フォルダを選ぶと一覧が表示される
- 1体を開いて編集・保存すると、JSONに反映され `edited: true` になる
- PNGとスプライトシートを書き出せる
- `_original` との比較表示が動く
- 手直し後に Claude Code へ依頼すると、`style-guide.md` に傾向が追記される

## 11. やらないこと

- サーバー、ログイン、クラウド保存
- 画像生成AIの利用
- レイヤー機能などの高機能化（必要になったら既存ツールへの書き出しで対応する）
