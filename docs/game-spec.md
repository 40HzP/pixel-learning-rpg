# ゲーム本体 設計書（Claude Code向け）

置き場所：`docs/game-spec.md`（ドット絵ツールの仕様書 `docs/spec.md` と並べる）
対象：アプリ案「起動中だけ主人公が強くなっていく暇つぶし系ローグライクドット絵ゲーム（勉強機能付き）」
設計ページ（正本）：https://app.notion.com/p/3e9bafd061fe8020af5cd7e51d08c4ab
問題リスト（正本）：https://app.notion.com/p/3f0bafd061fe80aa94a6d38dc9a6e41a

この設計書は、設計ページのうち **第1段階（試作）で作る部分** を実装できる粒度に落としたもの。設計ページと食い違うときは設計ページを優先し、食い違いを 40HzP に報告する。

---

## 0. 第1段階の目的

**面白さを確かめるための試作**。次の4つが回ることを確かめ、数値を調整できる状態にする。

1. 起動している間だけ主人公が自動で強くなる（放置）
2. 4択の勉強で、熟練・店の品揃え・戦闘が変わる（勉強）
3. 睡眠で熟練が上下する
4. 魔物（俗説）が問題に干渉し、図鑑が埋まっていく

絵は既存のスプライトと仮の図形、問題は Notion の10問で足りる。作り込みは第2段階以降。

---

## 1. 前提・制約（必ず守る）

- 40HzP はプログラミングをしない。**継続的な保守やデバッグが要る構成にしない**
- **ビルド工程なし・npm パッケージなし**。素の HTML / CSS / JavaScript（ES モジュール）で書く
  - テストは Node.js 組み込みのテストランナー（`node --test`）だけを使う
- 外部への通信をしない（CDN も使わない）。フォントはリポジトリに置く（6章）
- ドット絵ツールの決まりは変えない
  - `pixel/editor.html` とスプライトJSONの形式（`serializeSprite`）を変更しない
  - ゲームは `pixel/sprites/*.json` と `pixel/palette.json` を **読むだけ**。`_original/` と `export/` は読まない
  - スプライトをゲーム用にコピー・変換して置かない（手直しした瞬間にゲームへ反映されるようにする）
- 対象：スマホのブラウザ（縦画面）とデスクトップ版 Chrome。将来ストアアプリ化する（第3段階）ので、ブラウザ固有の機能に頼りすぎない

- 乱数は `sim.js` に渡す関数経由で使う（テストで固定できるように）

## 3. 遊び方の流れ（第1段階）

1. 初回起動：「最初の目的は7歳で遭遇する小学校教師をボコボコに倒すことだ」と表示し、**0歳から始める（準備期間が長い）／7歳から始める（すぐ戦えるが弱い）** を選ばせる（設計ページ「先のステージを見たくなる動機」）。チュートリアルは作らない
2. 冒険画面：主人公が階層を自動で進み、魔物と戦い続ける。経験値・ゴールドが増え、レベルが上がる
3. 勉強画面：4択を解く。正解すると熟練が上がり、店の品揃えが増え、今戦っている魔物にダメージが入る
4. 施設画面：店で装備を買う。寝床で眠る
5. 図鑑：出会った魔物の俗説と正体が埋まっていく
6. 7歳で小学校教師（中ボス）が出る。勉強で5問正解するまでダメージが入らない。倒すと仲間になる

## 4. ルール

数値はすべて `game/data/balance.json` に置く（8章に初期値）。下の文中の数値は初期値。

### 4.1 時間（「起動中だけ」）

- 現実の1時間＝ゲーム内の1年。現実1秒＝ゲーム内 8760/3600 ≒ 2.43時間
- **画面が見えている間だけ時間が進む**。`visibilitychange` で隠れたら止め、戻っても止まっていた分を取り戻さない
- 1フレームの経過時間は最大1秒で打ち切る（端末のスリープ明けなどに一気に進まないように）
- 表示：「◯歳 ◯月◯日 ◯時」。0歳1月1日0時から数える

### 4.2 自動冒険

- 1階層＝魔物5体。5体倒すと次の階層
- 第1段階は1〜9階層（背景は全階層 `bg_floor01`）。10階層目の小ボスは第2段階。9階層を越えたら9階層を繰り返す
- 主人公と敵が交互に自動で攻撃する（主人公1.0秒ごと、敵1.2秒ごと。現実の秒）
- ダメージ＝ max(1, 攻撃力 − 防御力÷2) に ±10% のゆらぎ
- 敵を倒すと経験値とゴールド。経験値が溜まるとレベルが上がり、ステータスが伸びる
- **やられたら**：階層だけ1に戻る。レベル・ステータス・装備・仲間はそのまま。同時に「睡眠」と同じ処理が起きる（4.5）
- 出てくる魔物：`monsters.json` の `kind: "monster"` から無作為。スプライトが無い魔物は仮の図形で描く（5.3）

### 4.3 勉強（4択）

**モード**

| モード | 内容 |
|---|---|
| クイズ | 全ジャンルから1問 |
| テスト | 指定ジャンルから5問 |
| 過去問復習 | 間違えた問題・俗説に騙された問題から出題 |

（設計ページの「学習」モードと暗記資料は第2段階）

**1問の流れ**

- 選択肢は「解答＋誤答1〜3」の4つを無作為に並べる
- 制限時間：☆10秒／☆☆20秒／☆☆☆30秒／☆☆☆☆45秒／☆☆☆☆☆60秒。時間切れは不正解
- 解答後に正誤と解説を出し、「次へ」で進む

**出題の選び方**

- 難易度の割合は、そのジャンルの熟練Lvで決める（8章の表）。クイズは全ジャンルの熟練の平均を四捨五入したLvを使う
- その難易度の問題が無ければ、近い難易度から選ぶ
- 直近5問と同じ問題は避ける。候補が無くなったら重複を許す（今は10問しかないため）

**正解したとき**

- そのジャンルの「正解数」を1増やす。**正解10回で熟練Lvが1上がる**（最大5）
  - 設計ページの「10問解く」を「10回正解する」と解釈した。同じ問題の再正解も数える（問題数が増えたら見直す）
- 累計正解数が増え、店の品揃えが増える（4.6）
- 今戦っている魔物にダメージ（最大HPの50%）

**間違えたとき**

- 過去問復習の対象に入れる

### 4.4 魔物の干渉と図鑑

- 問題の「関連する魔物」が **今戦っている魔物と同じ** とき、その問題は「干渉中」になる
  - 問題文の上に、その魔物の小さなアイコンと「◯◯が口を挟んでいる」を出す
  - 選択肢の見た目は変えない（どれが俗説か分からないようにする）
  - 正解：その魔物に大ダメージ（最大HPの100%＝撃破）
  - 誤答1（俗説）を選んだ：魔物が回復（最大HPの30%）、「騙された回数」を1増やし、過去問復習に入れる
- 勉強画面を開いている間も冒険は裏で進む。干渉の判定は **答えた瞬間** の敵で行う
- 図鑑の段階（設計ページ「図鑑との関係」）

| 段階 | 条件 | 見えるもの |
|---|---|---|
| 未遭遇 | まだ出会っていない | シルエットのみ |
| 遭遇 | 冒険で出会った | 名前と俗説 |
| 正体判明 | 撃破した、または関連する問題に正解した | 正しい知識（truth）と騙された回数 |

- `debated: true`（⚠）の魔物は、正体欄に「研究が割れている」と出す

### 4.5 睡眠

- 施設の寝床で眠る、またはやられたときに起きる
- ゲーム内時間が10時間進み、主人公と仲間のHPが全回復
- 熟練の判定（ジャンルごと）
  - 前回の睡眠以降に解いたジャンル：15%で熟練Lv+1（最大5）
  - 解いていないジャンルで熟練Lv1以上：5%で熟練Lv−1
- 判定結果を「睡眠のまとめ」として表示する（上がったジャンル・下がったジャンル）

### 4.6 店

- 品物は `items.json`。累計正解数が条件に届くと品揃えに並ぶ（勉強で増える）
- 買うのはゴールド（放置で稼ぐ）
- 武器・防具は買うと自動で装備する（前より強い場合）

### 4.7 中ボス：小学校教師

- 主人公が7歳になったあと、次に敵が出るタイミングで小学校教師が出る
- 出ている間は自動攻撃でダメージが入らない（「0」と表示）。冒険画面に「勉強で5問正解しよう」と出す
- 勉強で正解5回（ジャンル不問）で「防御が崩れた」状態になり、以後は自動攻撃でダメージが入る
  - 設計ページは「指定ジャンル」。小学校教師のジャンルは未定なので、第1段階ではジャンル不問にした
- 倒すと仲間になる。仲間は主人公の後ろに立ち、1.5秒ごとに攻撃する
- スプライト：`teacher_elementary_idle` / `teacher_elementary_attack`。中ボスは左向きに描かれているので、**仲間になったら左右反転して描く**

## 5. 画面

### 5.1 共通

- 縦画面。冒険の場面は **90×160 の論理解像度** のキャンバスに描き、整数倍で拡大する（背景が90×160のため）
  - `imageSmoothingEnabled = false`。拡大倍率は画面に収まる最大の整数
- 文字・ボタン・問題は HTML で重ねる（90px幅に日本語の文章は入らないため）
- 下にタブ：冒険／勉強／施設／図鑑。タップできる大きさは44px以上
- ダブルタップでの拡大を防ぐ。iPhone の画面端（safe-area）を避ける

### 5.2 冒険画面（設計ページ「自動冒険画面に必ず表示する項目」）

- ステータス（Lv・HP・攻撃・防御）
- 経験値：現在／次のLvまで、累計
- 所持金
- 秒間獲得経験値・ゴールド（直近60秒の平均）
- ゲーム内日時（4.1）
- 階層（◯階層 ◯/5体）
- 主人公・仲間・敵のスプライト、攻撃エフェクト、ダメージ数字、HPバー
  - 攻撃エフェクトはスプライトに描かず、ゲーム側で描く（`style-guide.md` 5章）。短い斬撃の線と、数字が浮き上がって消える演出
- 表示項目は空（y=0〜97）の部分に重ね、キャラクターの立つ地面（y=105〜150）を隠さない

### 5.3 スプライトの描き方

- `pixel/palette.json` の色キーでスプライトJSONを1倍のキャンバスに描き、フレームごとに保持する
- 待機アニメは `fps` に従う。攻撃したときだけ攻撃スプライト（`*_attack`）を1回流す
- 主人公・仲間は右向き、敵は左向きの絵をそのまま使う。向きを変えるときは左右反転で描く
- スプライトが無い・読めないとき：魔物と同じ大きさの暗色の四角に「？」を描く（止まらない）
- シルエット：スプライトの不透明な画素をすべて `0` の色で描く

### 5.4 勉強画面（設計ページ「勉強画面の表示」）

- 上部：ジャンル、熟練Lv（0〜5）、次のLvまで（10回中◯回）、有効な専攻2枠（第1段階は「—」）
- モード：クイズ／テスト（ジャンルを選ぶ）／過去問復習
- 出題中：問題文、4択、制限時間バー、☆難易度、干渉中の魔物アイコン
- 解答後：正誤、解説、図鑑の更新通知
- 隅に冒険の小窓（冒険画面と同じ描画を小さく）。勉強中も冒険が進んでいるのが見える

### 5.5 施設画面

- 店（4.6）、寝床（4.5）、仲間の一覧
- 会社・ロケット発射場・専攻の付け替え・拠点は「準備中」と表示

### 5.6 図鑑

- 魔物と中ボスの一覧。段階に応じた表示（4.4）

### 5.7 デバッグ画面（URL に `?debug=1` を付けたときだけ）

- 時間の速さ：×1 ／ ×60 ／ ×600
- ゴールド追加、年齢を設定、熟練を設定、すぐ眠る、セーブを消す
- セーブを文字列で書き出す／読み込む

## 7. データ

### 7.1 questions.json（Notion から生成。手で編集しない）

```json
{
  "generatedAt": "2026-10-14T00:00:00+09:00",
  "questions": [
    {
      "id": "3f8bafd0-61fe-81d8-9ca0-d781928aff39",
      "genre": "統計学",
      "subgenres": ["数学"],
      "difficulty": 1,
      "question": "イカサマのないサイコロで、6が5回続けて出ました。次に6が出る確率は？",
      "answer": "1/6",
      "wrong": ["1/6より低い。もう出尽くしたから", "1/6より高い。流れが来ているから", "1/2"],
      "explanation": "…",
      "monster": "ツギハクロ"
    }
  ]
}
```

Notion のプロパティとの対応：

| Notion | JSON |
|---|---|
| ページID | `id` |
| ` メインジャンル`（先頭に空白あり） | `genre` |
| サブジャンル | `subgenres` |
| 難易度（☆の数） | `difficulty`（1〜5） |
| 問題 | `question` |
| ` 解答`（先頭に空白あり） | `answer` |
| 誤答1・誤答2・誤答3 | `wrong`（**誤答1を必ず先頭**。誤答1が俗説の枠） |
| 解説 | `explanation` |
| 関連する魔物 | `monster`（空なら `null`） |

- 問題・解答・誤答が欠けているページは書き出さない（Notion に空のページが2件ある）

**「問題を同期して」と頼まれたとき**

1. Notion の問題リストを読む（Notion に接続できるなら直接。できなければ、40HzP に「問題リストを CSV で書き出して `game/data/notion-export/` に置いて」と頼む）
2. `questions.json` を書き出す
3. `node tools/check-questions.mjs` で検査する
4. 増えた問題・外した問題・警告を 40HzP に短く報告する

**check-questions.mjs が調べること**

- 4つの選択肢（解答＋誤答3つ）がそろい、重複していない
- `genre` が設計ページの29ジャンルのどれか
- `difficulty` が1〜5
- `monster` が `monsters.json` にある（無ければ警告。止めない）
- ジャンルごと・難易度ごとの問題数を表示する

### 7.4 セーブ

- `localStorage` のキー `plrpg.save`。中身に `version` を持たせ、版が変わったら `save.js` の移行処理で読み替える
- 10秒ごとと、画面が隠れたときに保存する

## 10. テストと確認

**自動テスト（`node --test game/tests/`）**

- 睡眠の熟練判定：乱数を固定して、上がる・下がる・変わらないの各場合
- 正解10回で熟練Lv+1、最大5で止まる
- 選択肢が4つで、解答が1つだけ含まれる
- 干渉：関連する魔物が敵のときに正解→撃破、俗説を選択→回復と騙された回数+1
- やられたとき：階層が1、Lv・装備・仲間は維持、睡眠処理が走る
- 時間：隠れている間は進まない。1フレーム最大1秒
- セーブの書き出し→読み込みで状態が一致する。古い版のセーブを移行できる
- 中ボス：正解5回までダメージ0、その後は通常

**画面の確認**

- 使える環境なら Playwright（ヘッドレスブラウザ）で、スマホ縦画面の大きさで起動→冒険→勉強→施設→図鑑を開き、スクリーンショットを撮って崩れを確かめる
