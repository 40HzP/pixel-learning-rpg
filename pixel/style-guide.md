# ドット絵スタイルガイド

Claude Code はドット絵を生成する前に必ずこのファイルを読む。
最後の「手直しの傾向」は、40HzP の手直しを比べて Claude Code が追記していく欄。**上の規則と食い違うときは「手直しの傾向」を優先する**（新しいほうが正しい）。

---

## 1. 共通の規則

- 色は `palette.json` の色だけを使う。`.` は透明
- **輪郭：1px の暗色（`0`）**。外周はすべて `0` で囲む
  - 体の内側の区切り（服の境目など）は、輪郭色ではなくその色の影色で描く
  - 目・口・手足の分かれ目には `0` を使ってよい
- **光源：左上**。明るい色は上側・左側に、影は右側・下側に置く
- 1つの素材の色は「明・中・暗」の3段階までにする（下の表）
- アンチエイリアス（中間色で輪郭をなめらかにすること）はしない
- ディザ（2色を市松に混ぜる表現）はキャラクターでは使わない。背景の空のグラデーションだけに使う
- キャラクター1体に使う色は10色前後までにする
- キャンバスの外にはみ出さない。武器や羽もキャンバス内に収める

### 色の段階（明・中・暗）

| 素材 | 明 | 中 | 暗 |
|---|---|---|---|
| 肌 | `7` | `6` | `5` |
| 茶（髪・革・木） | `a` | `9` | `8` |
| 青（服） | `n` | `m` | `l` |
| 緑（草・服） | `k` / `j` | `i` | `h` |
| 赤 | `e` | `d` | `c` |
| 黄・金 | `g` | `f` | `e` |
| 紫 | `r` | `q` | `p` |
| ピンク | `t` | `s` | `r` |
| 灰・金属 | `4` / `3` | `2` | `1` |
| 青緑 | `v` | `u` | `h` |

- 頬の赤み：`s` を1px（子どもだけ）
- 金属の光：刃の中央に `4`、ほかは `3`

## 2. 向き

- 主人公・仲間：**右向き**
- 敵（ザコ・ボス・中ボス）：**左向き**
- 左右対称に描いたほうが分かりやすい魔物（コウモリなど）は正面向きでよい

## 3. 人間キャラクター（16×16）

- **2頭身**。足元は最下行（15行目）に接地させる（0行目が一番上）
- 子ども（主人公・仲間）
  - 頭部：**縦8px**（1〜8行目。髪を含む）、**横10px**（輪郭を含む）
  - 体：縦7px（9〜15行目）
  - 目：縦2px・横1px の `0`。顔の向いている側に寄せる
  - 髪のハネなどは0行目にはみ出してよい
- 大人（中ボス・大人の仲間）
  - 頭部：**縦7px**（1〜7行目）、体：縦8px（8〜15行目）。子どもより体を1px長くして年齢差を出す
  - 目：1px、または眼鏡（`4` と `o` の2pxで光らせる）
- 持ち物は職業が一目で分かるものを1つ持たせる（小学校教師＝赤ペン、中学校教師＝ジャージと首の笛、高校教師＝指し棒、政治家＝たすきとマイク、大学教授＝分厚い本と白いあごひげ、就職面接官＝履歴書、学会の査読者＝白衣と虫眼鏡、税務調査官＝そろばん）
- 孫は例外で、主人公より小さな子ども（頭7行・体4行。上の空いたところに黄色い「？」）
- 学校の先生の正面の絵（`<先生>_scold`。テスト用紙を破りすてたときのミニモーションだけに出る）：近くから見せる絵なので例外で **32×32**。正面を向き、破れた用紙の左右を両手で胸の前に持って見下ろしている（上まぶたを下げ、黒目は内側の下。眉は外が上で内が下。口は大きく開ける）。用紙は白 `4` に灰色 `3` の罫線、破れた側の縁も `3`。右上に赤い怒りの印。2枚目は用紙を1px震わせ、口を広げ、怒りの印を小さくする。髪・服・小物はいつもの絵に合わせる（小学校教師＝眼鏡と耳の赤ペン、中学校教師＝ジャージ、高校教師＝白いシャツと赤いネクタイ、大学教授＝白い髪とひげ）。下の段は教卓（`scene_lectern`）で隠れる
- 困惑顔（`<先生>_puzzled`）：同じ形で顔だけ変える。眉は内が上・外が下（困り眉）、目は上まぶたを下げずに見開き（黒目は内側の下で用紙を見る）、口は黒いくにゃくにゃの線。頭の左に水色の汗、右上に白い「！」（輪郭なし。後ろは黒板。40HzP の依頼で「？」から変えた）。2枚目は口の波をずらし、「！」を1px下げる
- 大喜利の答案を持つ先生（`<先生>_oogiri_puzzled`・`_oogiri_stern`。テストに大喜利を書いて提出したときのミニムービーだけに出る）：破りすてるときの正面の絵と同じ形で、破れていない答案（白 `4`、右と下の縁は `3`、灰色の罫線と左に赤ペンの印 `d`）を両手で胸の前に持つ。困惑顔は破りすてるときと同じ顔（汗と白い「！」）。真顔は眉がまっすぐ、上まぶたを下げた目、口は横一本の線。小学校教師の真顔は眼鏡が白く光る（`4`、片隅だけ `3`）。真顔は1枚
- 赤面する主人公（`hero_blush`。大喜利のミニムービーだけに出る）：16×16・3枚。1枚目は剣を持たずに立つふつうの姿（あやまる絵の1枚目と同じ体で、目は開けている）。2・3枚目は顔の肌を `t`・`s` にして頬を赤 `d`、目はぎゅっとつぶる。頭の右上から湯気（白 `4` に灰色 `3`・`2` の縁。明るい壁の前でも見えるように）が2枚で昇る
- あやまる主人公（`hero_bow`。用紙を破りすてたときのミニモーションだけに出る）：前へ倒れた頭が入るように例外で **24×16**（左の16×16は主人公と同じ位置）。1枚目は剣を持たずに立ち、目をぎゅっとつぶって頭の横に汗（水色のしずく `n`・`o`・`m`）。2枚目は軽いおじぎ、3枚目は頭がひざの高さまで下がる深いおじぎ（顔は下向き、汗が飛ぶ）、4枚目は2枚目と同じ。fps 8 でくり返すと、ぺこぺことあやまる。足は動かさない
- 教室（`scene_classroom`、64×48）：灰色の壁・緑の黒板（木の枠とチョーク置き）・腰板・手前の教壇。先生は (16, 6)、教卓は (19, 34)、あやまる主人公は (0, 31) に重ねる
- 年を取った主人公（`hero_old_idle`。体の不調と寿命のミニムービーだけに出る）：主人公と同じ形・同じ服で、髪を灰色（`4`・`3`・`2`）、口もとに白いひげ（`4`）、頬の赤みなし。剣の代わりに杖（`9`。上を曲げた持ち手）をつく。2枚目は頭と胴を1px下げ、足と杖は動かさない

## 4. 魔物

- **ザコ＝俗説**、**ボス＝かつての誤った学説**を擬人化・擬物化したもの
- モチーフは設計ページの「敵キャラクター > 魔物系」の節を参照する
  - https://app.notion.com/p/3e9bafd061fe8020af5cd7e51d08c4ab
- 俗説の中身が一目で分かる仕掛けを1つ入れる
  - 例：サンビョウキンギョ＝体に「3」の模様、ジュッパーノウ＝ナイトキャップをかぶって寝ている脳、ミエナイコウモリ＝目隠し
- 図鑑の未遭遇の段階ではシルエットだけを見せるので、**シルエットだけで見分けられる外形**にする
- 怖くしすぎない。少しとぼけた表情にする（俗説は「もっともらしいけれど間違い」なので）
- サイズ：ザコ 16×16、ボス 32×32
- 月面のザコ（`world: "moon"`。月の俗説）：月そのものを擬人化したものが多いので、体の色を黄色い月（`g`・`f`）と灰色の月（`4`・`3`・`2`）に分け、持ち物や付け足しで形を変える（ジブンデヒカル＝光の筋とランプのひも、ジテンシナイ＝画びょう、フワフワツキ＝風船、アオイツキゾラ＝青空柄の傘、マンゲツソウドウ＝回転灯、ハナレナイツキ＝鉄球と足かせ、ズットサムイ＝毛糸の帽子とマフラー など）。月面の地面は灰色（`2`）なので、灰色の月は輪郭 `0` で地面から分ける

- 月面のボス（32×32。設計ページ「小ボス：月面」の見た目のとおり）：カンペキキュウ＝すました顔の白い球（`4`・`3`。正解で描き足す差分 `kanpekikyuu_marked1`・`marked2` はクレーターと山の影 `3`・`2` を足していき、顔も困っていく。攻撃の絵は無く、待機の絵で前に出る）、ガリレオチョウセキ＝左側にだけ青い波（`l`・`m`・`n`、波頭 `4`）を抱えた黄色い月にとがったあごひげ、ツキジンセツ＝白い羽の生えた月の顔の住人（紫の服）が新聞のビラ（白に灰の線）を持つ、ツキノウミセツ＝青い水を満たした黄色い盃（倒したあとの `tsukinoumisetsu_dry` は黒い平原と「静かの海」の立て札）、チリノウミセツ＝灰色の塵の山に歯の並んだ大きな口、ブンレツセツ＝青い地球から灰色の雫の月がちぎれかけている（分かれた姿は `bunretsusetsu_earth`・`bunretsusetsu_moon`、24×24）

## 5. アニメーション

- 待機（2枚、fps 3〜4）
  - 1枚目が基本の姿。2枚目は頭と胴を1px下げる（呼吸）
  - 羽・ひれ・しっぽは2枚目で形を変える
- 攻撃（2枚、fps 6）
  - 1枚目：構え（振りかぶる）。2枚目：武器を前に突き出す
  - 攻撃エフェクト（斬撃の軌跡など）はスプライトに描かない。ゲーム側で別に出す

## 6. 背景（90×160、縦長）

- 輪郭は付けない
- 遠景ほど空の色に近づける（遠い山は淡い色、近い森は濃い色）
- 地面の始まり（地平線）は y=98 付近。キャラクターは y=105〜150 あたりに立つ想定
- キャラクターが立つ地面には細かい模様を入れすぎない（キャラクターが埋もれるため）
- 階層の世界観は10階層ごとにジャンル単位で切り替える（設計ページ「先のステージを見たくなる動機」）
  - 今の世界（`game/data/stages.json`）：草原（1〜）・生き物の森（11〜）・平安京（21〜）・錬金術の工房（31〜）・ピラミッドの砂漠（41〜）・火山（51〜）・氷の大地（61〜）・夜の都会（71〜）・海の底（81〜）・天空の神殿（91〜）
  - 世界ごとに地面の色を変える（キャラクターの輪郭 `0` が埋もれないよう、地面は中くらいの明るさにする）。上の方（y=0〜64 あたり）は冒険画面のステータスに隠れるので、世界の目印は y=40〜100 に置く

- 月面（`bg_moon`）：空は真っ黒（`0`。月には大気がほとんど無いので昼でも黒い）に星（`4`・`3`・`2` の点）。地球を y=66〜86 の右寄りに浮かべる（青 `m`・明るい青 `n`、陸 `i`、雲 `4`。右下は夜の側で `l`・`h`）。地平線の手前に暗い山並み（`1`、稜線だけ `2`）。地面は月の砂（`2`）に明るい粒（`3`）と暗い粒（`1`）。クレーターは輪郭なしの楕円で、左上の内側を影（`1`）、右下の縁を明るく（`3`）。地平線の近くは小さく、手前ほど大きく。キャラクターが立つ所（y=112〜150 の真ん中）にはクレーターを置かない

## 7. 既存作品に似せない

- 既存の作品のキャラクターやデザインに似せない
- 特定の作品の主人公として知られている「服の色＋帽子＋武器」の組み合わせは避ける
- 魔物は既存作品のモンスターの形を借りず、俗説・学説の中身から形を決める

## 8. ファイル名とカテゴリ

- ファイル名：`<対象>_<動き>.json`。ローマ字の小文字とアンダースコア（例：`hero_idle`、`teacher_elementary_attack`）
- 背景：`bg_floorNN`（NN はその世界の最初の階層。11〜20階層なら `bg_floor11`）
- 街の背景：`bg_town`。施設の外観：`town_<施設>`（例：`town_shop`。動きが1つだけなので `_idle` は付けない）
- `category` の値

| category | 対象 |
|---|---|
| `character` | 主人公・仲間 |
| `midboss` | 中ボス（専門職の人間） |
| `monster` | ザコ魔物 |
| `boss` | ボス（かつての学説） |
| `background` | 階層の背景 |
| `icon` | アイコン（8×8。下の切り替えバー・テストのジャンルと勉強のメニューのボタン・店の品物のアイコンは 16×16。10〜12章） |
| `building` | 施設の外観（32×32） |

## 9. 施設の外観（32×32）と街

- 施設画面は「街」。`bg_town`（90×160）の上に施設の外観を並べ、主人公が広場に立つ。並べる位置は `game/data/town.json`
- 外観は**正面から少し見下ろした形**：上に屋根、下に正面の壁と入口。入口は手前（下）の道に向ける
  - 寝床は家ではなくテント（三角の布の正面に入口。布の左半分を明るく、右の縁を暗く）。屋根と壁の形でなくてよい
- 地面に接するのは最下行（31行目）。外周は `0` の輪郭で囲む（背景と違い、建物には輪郭を付ける）
- 光源は左上：屋根は左半分を明るく、壁は右端を1段暗く、軒の下に影の線を入れる
- **何の施設か一目で分かる看板・目印を1つ入れる**（店＝剣の紋章と品物の窓、仲間が集まる場所＝3人の看板、寝床＝テントの入口からのぞく寝袋とたき火、会社＝グラフの看板、ロケット発射場＝ロケット、専攻の付け替え＝時計塔、拠点＝足場と工事中の柵、病院＝屋上の白い看板に緑の十字。赤い十字は赤十字の標章なので使わない）
- 屋根の色で見分けやすくする（同じ色の屋根を隣に並べない）
- 動くのは煙・旗・ランプなど小さな部分だけ（2枚、fps 2）。準備中の施設もふつうに描く（「準備中」の札はゲームが重ねる）
- 街の背景：道は砂色 `b` の縁を `a`、草は `j` に `k`・`i` を散らす。建物の前の道は幅6px。輪郭は付けない
- 真ん中の道の下の端（道を幅16pxに広げた小さな広場。寝床と病院の間）に今日の1問の掲示板を置き、主人公はその上の道に立つ
- 月面の街（`bg_moon_town`、`town.json` の `moon`）：上の帯（y=0〜26）は黒い空と星、地球は上の帯の字（所持金・版）に重ならない真ん中。その下は月の砂とクレーター（月面の背景と同じ描き方）。道は明るい月の砂（`3`）。帰還ロケットの発着場（灰色の楕円）は背景に描き、ロケットの絵（`town_moon_rocket`）はその上に立つ（ミニムービーで同じ場所に降りるため）
  - 帰還ロケット（`town_moon_rocket`）：飛ぶロケット（`rocket_flight`）と同じ形のロケットが着陸の脚で立つ。先端の灯りが点滅（2枚）
  - 月面基地（`town_moon_base`）：白い半球のドーム（継ぎ目のパネル、丸窓、左下に出た入口、右に太陽電池）。アンテナの赤い灯りが点滅（2枚）
- ロケットのミニムービーの絵：`scene_launchpad`（90×160。地球の打ち上げ場：空のグラデーション、海、草地、コンクリートの台と炎の逃げ道、赤い鉄骨の発射塔）と `rocket_flight`（16×48・3枚。上の30行がロケット、1枚目は炎なし、2・3枚目は下に炎。白い胴 `4`・`3`、赤い先端と羽 `d`・`c`、丸窓 `o`・`n`。地球の街の `town_rocket` と同じ見た目）。category は `background`
- 今日の1問の掲示板：`town_board`（16×16・3枚。category `building`）。街の下の広場に置く。赤い小さな屋根、コルクの板（砂色にところどころ明るい茶の点）、2本の足。1枚目は何も貼っていない、2枚目は赤い画びょうで白い紙（紺の「？」）を留めたもの、3枚目はその紙に赤い丸の印（答えた）。ゲームは時間で動かさず、今日の1問の様子で絵を選ぶ

## 10. 下の切り替えバーのアイコン（16×16）

- ゲームの下の「冒険」「勉強」「街」「図鑑」のボタンに、字の上に2倍で出す。`icon_adventure`（剣）・`icon_study`（用紙と鉛筆）・`icon_town`（家並み）・`icon_zukan`（本と虫めがね）。category は `icon`、1枚
- 暗い帯（`#262139` くらい）の上に出るので、中の色は明るめにする。外周は `0` の輪郭で囲む。光源は左上
- 何の画面か一目で分かる物を1つ（多くて2つ）だけ描く。細かい模様は入れない（32px で見える大きさ）
- 斜めの線（剣・鉛筆）は、横に2つ並べた点を1段ずつずらして描く（斜めに1つずつ並べると、輪郭が市松模様になって途切れて見える）
- 選んでいない画面のアイコンはゲームが少し暗くするので、暗い版は描かない

## 11. テストのジャンルのボタンのアイコン（16×16）

- 勉強の「テスト」でジャンルを選ぶボタンに、2倍で出す。`genre_<ジャンルのローマ字>`（化学は `genre_bakegaku`、科学は `genre_kagaku`）。category は `icon`、1枚。どのジャンルにどのアイコンかは `game/data/genre-groups.json`
- 描き方は10章と同じ（16×16・外周は `0` の輪郭・光源は左上・物は1つか2つ・斜めは2つずつずらす）。ボタンはまとまりの色を薄く敷いた暗い地なので、中の色は明るめにする
- ジャンルの中身が一目で分かる物を描く。ほかのジャンルと形がかぶらないようにする
  - ことば：現代文＝用紙に「文」、古文漢文＝巻物、難読漢字＝「字」と赤い「？」の札、言語学＝2つの吹き出し、外国語＝「A」の吹き出し
  - 数学：数学＝三角定規、統計学＝棒グラフ
